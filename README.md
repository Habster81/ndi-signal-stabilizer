# NDI Signal Stabilizer

**Stable resolution. Reliable NDI signals.**

NDI Signal Stabilizer is a Windows application designed to maintain a constant output resolution and frame rate for NDI video streams, even when the source dynamically changes its video format.

It is particularly useful in live productions, conference environments, presentations and professional AV installations using NDI-to-HDMI or NDI-to-SDI decoders.

## Why NDI Signal Stabilizer?

Some NDI sources, including video conferencing applications such as Microsoft Teams, may dynamically reduce their output resolution when network bandwidth becomes limited.

When these signals are converted to HDMI or SDI, resolution changes can cause display flickering, scaling issues or temporary signal interruptions.

NDI Signal Stabilizer receives the incoming NDI stream, scales it to a predefined output format and publishes it as a separate NDI source on the network.

This provides a consistent video format for downstream equipment.

## Key Features

- **Up to 5 independent NDI channels** – Process multiple NDI sources simultaneously with individual channel settings.
- **Fixed output resolution** – Select 720p or 1080p.
- **Selectable frame rates** – 25, 29.97, 30, 50, 59.94 or 60 fps.
- **Flexible processing** – Auto, GPU or CPU processing modes, with CPU fallback if GPU processing fails in Auto mode.
- **Optional stereo audio** – Enable audio individually for each channel.
- **Persistent configuration** – Source selection, output names and channel settings are saved.
- **System monitoring** – Integrated CPU and GPU usage indicators.
- **Multilingual interface** – German and English.
- **Optional autostart** – Launch automatically after Windows login.
- **Optional update checks** – Check for newer versions when starting the application.
- **Version archive** – Access previous versions and release notes.

## System Requirements

- Windows 10 or Windows 11 (64-bit)
- Microsoft .NET Framework 4.8
- Compatible NDI Runtime
- Sufficient CPU or GPU processing resources

The installer checks the required components during installation.

## Important Notes

NDI Signal Stabilizer maintains a constant output video format. It cannot restore image details or frames already lost at the source.

Performance depends on the computer hardware, input formats and number of active channels.
